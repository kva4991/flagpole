# Лицензия пока не выбрана

Репозиторий планируется публичным, но лицензия для исходного кода, документации, изображений и 3D-моделей пока не выбрана.

Без отдельной лицензии автор сохраняет исключительные права по умолчанию. Публичная доступность репозитория сама по себе не означает разрешение на копирование, модификацию или коммерческое использование.

Перед тем как разрешать использование проекта другими людьми, нужно отдельно решить:

- лицензию для прошивки и Android-кода;
- лицензию для документации;
- лицензию для STL/GLB и шаблонов флага;
- допустимость коммерческого использования и обязательность указания автора.
