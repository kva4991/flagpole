# Android-приложение управления

## Изменяемое название

Видимое имя программы и искомое BLE-имя задаются в корневом файле:

```text
project_identity.json
```

После изменения выполнить:

```powershell
npm.cmd run identity:generate
```

Технический package `ru.quicktickets.crucian` сохраняется отдельно и не влияет на видимое название.

## Реализованные функции

- поиск BLE-устройства по generated-имени;
- явная машина состояний;
- MTU negotiation;
- системный bonding/PIN;
- последовательная очередь GATT-операций;
- подписка на статус;
- AUTO/ON/OFF;
- ручная яркость;
- калибровка дня и ночи;
- смена PIN;
- команда отключения BLE;
- отображение света, температуры, влажности и давления;
- корректное закрытие GATT и остановка сканирования.

Напряжение аккумулятора намеренно не отображается: в проекте нет аппаратного измерителя этой величины.

## Машина состояний

```text
IDLE
 → SCANNING
 → CONNECTING
 → NEGOTIATING_MTU
 → BONDING
 → DISCOVERING_SERVICES
 → SUBSCRIBING
 → READING_CONFIGURATION
 → READY
```

Ошибки переводят клиента в `ERROR`. Ручное отключение использует `DISCONNECTING`.

## Очередь GATT

В каждый момент выполняется только одна операция. Следующая запускается после callback предыдущей или после ошибки/тайм-аута.

## Что проверить на телефоне

- разрешения Android 8–15;
- системный PIN-диалог;
- неверный PIN;
- смену PIN и удаление старого bond;
- повторное подключение;
- потерю связи во время каждой фазы;
- несколько последовательных команд;
- уход приложения с экрана и уничтожение ViewModel.
