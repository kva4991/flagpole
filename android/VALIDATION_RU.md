# Проверка Android-клиента — v0.7.5

Исходники приложения синхронизированы с версией `0.7.5`: `versionCode = 4`, `versionName = "0.7.5"`. Функциональный код BLE не менялся относительно последней успешно собранной линии. Сборку этой версии выполняет GitHub Actions после публикации.

Локальная сборка `:app:assembleDebug` успешно выполнена 2026-08-02 в защищённой рабочей папке. Два предупреждения относятся к намеренному legacy fallback для Android API ниже 33. GitHub Actions run [`30753133808`](https://github.com/kva4991/flagpole/actions/runs/30753133808) для commit `a80263a` также успешно собрал и опубликовал debug APK как workflow artifact.

Реальная проверка требует Android-телефон и ESP32-C3: сканирование, bonding, MTU, очередь GATT, смена PIN, команды AUTO/ON/OFF и отключение BLE.
