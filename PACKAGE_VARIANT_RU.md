# Вариант пакета

Это полный проект v0.5, подготовленный для передачи и первоначального размещения в публичном GitHub-репозитории.

Инженерная версия механики и электроники не изменена. Добавлены только:

- публичный `README.md`;
- подробная задача следующему агенту;
- краткий готовый prompt;
- памятка по подготовке публичного репозитория;
- `.gitignore` и `.gitattributes`;
- обновлённый manifest;
- пересчитанные контрольные суммы.
