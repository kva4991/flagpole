# Безопасность BLE и публичного репозитория

- BLE-имя устройства: `Crucian`.
- PIN по умолчанию в исходном коде является демонстрационным и должен быть сменён.
- Смена PIN требует старый PIN.
- После смены PIN прошивка удаляет сохранённые bond-записи, чтобы старые авторизации перестали работать.
- BLE не должен оставаться доступным бесконечно без успешной авторизации: окно после подачи питания — один час.
- После успешной авторизации BLE работает до сброса питания или команды `BLE:OFF`.
- Не добавляйте в публичный Git реальные ключи, пароли, адреса и персональные данные.
