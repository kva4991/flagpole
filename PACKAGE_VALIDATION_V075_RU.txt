НЕ ВЫДАЁТСЯ ЗА ПРОВЕРЕННОЕ В ЭТОМ ПАКЕТНОМ ОКРУЖЕНИИ
- Полная регенерация реальных STL/GLB/PNG требует полного локального checkout исходного репозитория.
- Android APK и обе прошивки не собирались внутри update-overlay.
- Координаты выносок структурно валидны, но после регенерации реальных изображений требуется визуально проверить попадание линий и удобство hotspots на основных ракурсах.

Обычный запуск APPLY_UPDATE_V075.ps1 без -SourceOnly выполняет полную регенерацию, quality gate и только после их успеха создаёт полный кумулятивный ZIP checkout.

ПРОВЕРКА ПРИ ИНТЕГРАЦИИ В ПОЛНЫЙ CHECKOUT
- Манифест исходного update-overlay проверен: 25/25 SHA-256 совпали.
- При первом полном запуске обнаружено, что применитель не передаёт выбранный Python во вложенный npm-процесс. Из-за этого `scripts/runPython.mjs` выбрал системный Python без Pillow. Интеграционная проверка завершена с явно заданным `FLAGPOLE_PYTHON`; сам launcher поддерживает эту переменную. Для будущего повторного применения архива переменную следует задавать заранее либо исправить применитель.
- Исходный ADR-0026 не соответствовал обязательному формату ADR проекта: регистр статуса и три обязательных раздела исправлены до финального quality gate.
- В полном checkout с реальными артефактами пройдены 39/39 Node-тестов, проверены 95 Markdown-файлов, 40/40 STL и семантика 7 GLB; 14 аннотированных PNG воспроизводятся без расхождений.
- Android и обе прошивки должны быть подтверждены GitHub Actions после публикации; физический образец не проверялся.
