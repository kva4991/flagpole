# Шаблон рыбы для флага — версия для 16-мм светящейся ленты

В проект добавлен согласованный шаблон рыбы (ихтис) с учётом текущей концепции:

- хвост слева;
- основная светящаяся лента идёт строго по стандартному контуру ихтиса, без лишних декоративных элементов;
- лента/неон имеет ширину **16 мм**;
- светоотражающая вставка в теле рыбы является **отдельной внутренней деталью**;
- светоотражающая вставка в хвосте является **отдельной деталью**;
- глаз не подсвечивается, а **вырезается насквозь**.

## Вложенные файлы

- `FISH_TEMPLATE_APPROVED_REFERENCE.png` — согласованный визуальный образец;
- `fish_template_clean_A4_landscape.svg` — чистый шаблон без размеров;
- `fish_template_clean_A4_landscape.png` — PNG-превью чистого шаблона;
- `fish_template_dimensioned_A4_landscape.svg` — шаблон с размерами;
- `fish_template_dimensioned_A4_landscape.png` — PNG-превью шаблона с размерами.

## Основные размеры

- Формат листа: **A4, альбомная ориентация** (297 × 210 мм)
- Общая длина рыбы: **примерно 249 мм**
- Общая высота по хвосту: **примерно 106 мм**
- Максимальная высота тела рыбы: **примерно 86 мм**
- Ширина светящейся ленты/неона: **16 мм**
- Диаметр отверстия глаза: **16 мм**

## Примечание по ткани

Предполагается следующая логика раскроя:

1. По толстому контуру прокладывается и/или пришивается светящаяся лента.
2. Внутри тела рыбы вырезается окно и вшивается отдельный кусок светоотражающей ткани.
3. Внутри хвоста отдельно формируется треугольная вставка из светоотражающей ткани.
4. Глаз вырезается как отдельное сквозное круглое отверстие.

## Примечание по корректировке

Размеры этой версии являются рабочими и подходят для печати шаблона в масштабе 100%.
Если после примерки реальной 16-мм ленты выяснится, что нужно увеличить радиусы на носу или в зоне пересечения хвоста, шаблон можно скорректировать в следующей версии проекта.
