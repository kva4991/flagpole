# Источники справочных изображений

Справочные изображения иллюстрируют только тип детали и не являются фотографиями купленных экземпляров. Точные источники также приведены в карточках `catalog/components.json`.

- `reference_petg_filament_wikimedia.jpg` — «1 kg petg filament in packaging.jpg», автор Suit, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:1_kg_petg_filament_in_packaging.jpg), лицензия CC BY-SA 4.0; файл не изменён.
- `reference_ptfe_sheet_public_domain.jpg` — «PTFEseet.JPG», автор NA, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:PTFEseet.JPG), public domain; изображение показывает только внешний вид PTFE-заготовок, не пористую вентиляционную мембрану.
- `reference_grease_container_public_domain.jpg` — «Grasso SKF per cuscinetti.jpg», автор Cav, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Grasso_SKF_per_cuscinetti.jpg), public domain; изображение показывает обычную упаковку смазки, не MOLYKOTE 111.
