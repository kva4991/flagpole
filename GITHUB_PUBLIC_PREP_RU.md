# Публичный GitHub-репозиторий: текущий статус и правила

Репозиторий уже опубликован: `https://github.com/kva4991/flagpole`. Версия v0.7.4 находится в `main` на commit `a80263a`; GitHub Actions run `30753133808` завершён успешно.

Перед следующей публикацией изменений:

1. Работать в отдельной ветке от актуального `main`.
2. Проверить `git status --short --branch` перед каждым коммитом.
3. Убедиться, что в файлах нет приватных адресов, токенов и локальных абсолютных путей.
4. Отдельно выбрать лицензию. Не добавлять случайную лицензию только потому, что репозиторий публичный.
5. Решить, нужен ли Git LFS для STL и GLB. Ни один текущий файл не превышает обычный лимит 100 МБ, однако суммарный объём бинарных моделей велик.
6. Не коммитить ZIP-пакеты внутрь самого репозитория: архив предназначен для передачи, а исходные файлы уже лежат в дереве проекта.
7. Создавать новый тег только по отдельному решению владельца и после проверок.
8. В описании репозитория явно указать, что это экспериментальный механический и электронный прототип для самостоятельной сборки.

Ближайшие осмысленные типы следующих коммитов:

```text
Docs: record measured pole and component dimensions
CAD: update parametric dimensions from physical measurements
Firmware: validate ESP32-C3 build and deep-sleep behavior
Test: add bearing, waterproofing and thermal test results
```
