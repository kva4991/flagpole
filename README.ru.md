# Вращающееся навершие флагштока Crucian v0.7.5

Crucian — экспериментальный проект вращающегося навершия для небольшого флага с подсвеченным контуром рыбы. Репозиторий объединяет печатную механику PETG/TPU, подсветку 12 В, прошивку ESP32-C3, BLE-управление, Android-приложение и автономный каталог компонентов, чертежей и 3D-моделей.

Актуальная кумулятивная версия — **v0.7.5**. Текущая механика снова полностью строится параметрическим генератором, без использования переходных сеток v0.7.3 как источника геометрии.

Основные изменения:

- на всех текущих винтовых соединениях предусмотрены обслуживаемые закладные M4/M3 и отдельные купоны для обеих гаек;
- два провода Ø2 мм проходят по открытой приподнятой дорожке с просветом 4,2 мм и бортами 2,5 мм ниже крепежа;
- у отмеченной владельцем точки установлен сменный TPU95-держатель `#tpu95-10`, направленный примерно на 35° вниз к флагу;
- верхняя лямка привязана к нижней кромке навершия: верхняя линия пришивания находится на 10 мм ниже неё;
- световой тоннель VEML7700 укорочен до 15 мм и получил отдельную клеевую полку с кольцевым резервуаром;
- карман AHT20+BMP280 рассчитан на самоклеящуюся мембрану Ø20 мм с рабочим центром Ø10 мм и семью отверстиями Ø2 мм;
- в боксе добавлен съёмный двухуровневый каркас: DC-DC снизу, ESP32-C3 и MOSFET вертикально на противоположных стенках, VEML7700 на отдельной опоре;
- ненужные карточки контактного листа и растрового образца рыбы заменены рабочими картами крепежа и компоновки электроники.

Жёсткие детали рассчитаны на уже купленный оранжевый PETG. TPU 95A используется для функциональных мягких элементов, TPU 85A — для статических прокладок. ASA остаётся возможной будущей заменой после повторной печати купонов.

## С чего начать

1. Прочитать [быстрый вход для нового чата](docs/agent-fast-start.ru.md).
2. Проверить [текущий статус реализации](docs/current-implementation-status.ru.md).
3. Открыть [отчёт v0.7.5](UPDATE_REPORT_V075_RU.md) и [аудит чертежей](docs/DRAWING_AUDIT_V074_RU.md).
4. Перед изменением архитектуры открыть [индекс ADR](docs/architecture/decisions/README.ru.md).
5. Перед печатью заполнить [таблицу обязательных измерений](MEASUREMENTS_REQUIRED_RU.md).
6. Компоненты, изображения и вращаемые 3D-модели смотреть в [локальном каталоге](catalog/catalog.html).

## Актуальные материалы

- `mechanical/generate_models_v06.py` — единственный источник текущей геометрии;
- `mechanical/stl_petg_v06/`, `mechanical/stl_tpu95_v06/`, `mechanical/stl_tpu85_v06/` — текущие детали;
- `mechanical/test_coupons_v06/` — обязательные купоны;
- `mechanical/flagpole_finial_v0_6_*.glb` — семь текущих интерактивных моделей;
- `catalog/drawings.json` — реестр всех текущих и исторических изображений и моделей;
- `mechanical/fastener_captive_nut_map_A4_landscape.svg` — карта всех закладных;
- `mechanical/electronics_layout_A4_landscape.svg` — компоновка электроники.

Имена файлов с `v0_6` сохранены для совместимости ссылок, но их содержимое соответствует v0.7.5.

## Локальный каталог компонентов, чертежей и 3D

Из корня проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\windows\open-component-catalog.ps1
```

Скрипт запускает сервер только на `127.0.0.1`, открывает `catalog/catalog.html` и оставляет интерактивные GLB доступными для вращения. Остановить сервер можно сочетанием `Ctrl+C`.

## Проверки

```powershell
python mechanical/generate_models_v06.py
python mechanical/validate_models_v06.py
python mechanical/render_previews_v06.py
python mechanical/render_part_id_drawings_v06.py
python mechanical/render_flag_power_route_v06.py
python mechanical/generate_reference_diagrams_v06.py
python mechanical/generate_detail_diagrams_v075.py
python mechanical/generate_hermeticity_diagram_v075.py
python electronics/generate_electronics_diagrams_v075.py
npm.cmd run catalog:generate
npm.cmd run quality:gate
```

Программные проверки подтверждают воспроизводимость файлов и топологию STL. Они не подтверждают посадки реальных деталей, герметичность, прочность, нагрев, срок службы на солнце или работу электроники.
