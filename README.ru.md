# Вращающееся навершие флагштока Crucian v0.7.0

Crucian — открытый инженерный проект вращающегося навершия для небольшого флага-ихтиса. Репозиторий объединяет печатную механику PETG/TPU, подсветку 12 В, прошивку ESP32-C3, локальное BLE-управление, Android-приложение и автономный каталог компонентов, чертежей и 3D-моделей.

Актуальная переданная версия — **v0.7.0**. Жёсткие детали текущей сборки рассчитаны на уже купленный оранжевый PETG; ASA остаётся возможной будущей заменой, когда появится бюджет. Это прототип, а не готовое серийное изделие: посадки и работа на реальном оборудовании требуют проверки.

## С чего начать

1. Прочитать [быстрый вход для нового чата](docs/agent-fast-start.ru.md).
2. Проверить [текущий статус реализации](docs/current-implementation-status.ru.md).
3. Ознакомиться с [отчётом обновления v0.7.0](UPDATE_REPORT_V070_RU.md).
4. Перед изменением архитектуры открыть [индекс ADR](docs/architecture/decisions/README.ru.md).
5. Перед изменением геометрии заполнить [таблицу обязательных измерений](MEASUREMENTS_REQUIRED_RU.md).
6. Комплектующие, материалы, чертежи и вращаемые 3D-модели смотреть в [локальном каталоге проекта](catalog/catalog.html).

## Принятая архитектура

- текущая сборка печатается из уже купленного оранжевого PETG; ASA рассматривается только как будущая замена после повторной печати посадочных купонов;
- TPU 95A используется для функциональных мягких деталей, TPU 85A — для более деформируемых прокладок;
- углепластиковая спица предварительно принята Ø5 мм, находится между двумя подшипниками и не пересекает ось древка;
- питание формируется аккумуляторным блоком 6×18650 и стабилизируется до 12 В;
- ESP32-C3 управляет одноцветным круглым неоном XUNATA 12 В через MOSFET и PWM;
- VEML7700 калибруется после сборки;
- BLE-имя устройства — `Crucian`;
- Android-приложение работает локально, без облачного сервера.

Подробные и исторические решения не переписываются задним числом: они ведутся через [нумерованные ADR](docs/architecture/decisions/README.ru.md). Текущее состояние отдельно фиксируется в [статусе реализации](docs/current-implementation-status.ru.md).

## Структура

- `mechanical/` — генераторы, STL, GLB, тестовые купоны и документы печати;
- `electronics/` — схемы, BOM и две линии прошивки: сохранённая v0.5 и новый прототип Crucian v0.6;
- `android/` — каркас локального BLE-приложения;
- `catalog/` — автономный каталог компонентов, генерируемый из JSON;
- `docs/` — точка входа, текущий статус, аудит, rationale и ADR;
- `scripts/`, `tools/quality/`, `tests/` — локальные проверки документации и структуры.

## Страница материалов, компонентов и чертежей

Готовая страница [`catalog/catalog.html`](catalog/catalog.html) объединяет комплектующие, расходники, материалы конструкции, чертежи и интерактивные GLB-модели. Из корня репозитория на Windows её можно запустить одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\windows\open-component-catalog.ps1
```

Скрипт поднимает сервер только на `127.0.0.1` и открывает каталог в браузере. Исходные данные находятся в `catalog/components.json` и `catalog/drawings.json`; сгенерированный `catalog/catalog.html` вручную не редактируется.

## Проверки документации

```powershell
npm.cmd run quality:docs:all
npm.cmd run catalog:check
npm.cmd test
npm.cmd run review:impact
npm.cmd run checksums:check
```

Проверки не заменяют сборку PlatformIO/Gradle и испытания на настоящих плате, телефоне, токосъёмнике, ленте и напечатанных деталях.
