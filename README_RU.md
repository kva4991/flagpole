# Вращающееся навершие флагштока v0.5

Версия v0.5 переработана под уже купленные материалы:

- несущие и корпусные детали — **оранжевый PETG**;
- мягкие вкладыши, прокладки и разгрузочные втулки — **белый TPU 95A**;
- сопло — **0,4 мм**;
- две опоры вращения — подшипники **6804-2RS**;
- углепластиковая спица расположена строго между подшипниками;
- миниатюрный токосъёмник M125 предполагается разместить внутри полого древка;
- электроника размещена с противоположной от флага стороны;
- доступ к электронике осуществляется через отдельную сервисную крышку с TPU-прокладкой.

## Важный статус версии

Это печатаемый инженерный прототип, но размеры древка, внутреннего отверстия древка, токосъёмника, углепластиковой спицы и фактическая посадка подшипников ещё должны быть подтверждены измерениями.

Перед полноразмерной печатью обязательно напечатать тестовые образцы из папки `mechanical/test_coupons/`.

## Основные файлы

### Модели для Blender

- `mechanical/flagpole_finial_v0_5_assembly.glb` — сборка;
- `mechanical/flagpole_finial_v0_5_print_layout_PETG.glb` — раскладка оранжевых PETG-деталей;
- `mechanical/flagpole_finial_v0_5_print_layout_TPU.glb` — раскладка белых TPU-деталей;
- `mechanical/create_blend_file.py` — импорт GLB в Blender и сохранение `.blend`.

### STL из PETG

Папка: `mechanical/stl_petg/`.

- две половины вращающегося корпуса;
- сервисная крышка;
- световой тоннель датчика;
- две половины неподвижного воротника древка.

### STL из TPU 95A

Папка: `mechanical/stl_tpu/`.

- две половины мягкого вкладыша углепластиковой спицы;
- две половины гермоввода/разгрузки кабеля к флагу;
- две половины разгрузки пучка проводов M125;
- прокладка сервисной крышки;
- втулка M125 внутри полого древка;
- две половины мягкой обоймы неподвижного воротника на древке.

## Главное правило материалов

PETG воспринимает нагрузку. TPU только:

- распределяет прижим;
- защищает углепластик от точечного смятия;
- разгружает кабели;
- компенсирует небольшие отклонения размеров;
- уплотняет статические разъёмные соединения.

TPU не используется между подшипником и корпусом и не заменяет металлические распорки, шайбы или крепёж.
