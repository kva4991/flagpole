## Главные нерешённые точки

1. Проверить реальную схему конкретного MOSFET-модуля, если будет использован модуль с LR7843.
2. Уточнить реальные размеры новых механических деталей после получения пользователем.
3. Проверить на устройстве работу BLE-bonding и смены PIN на Android.
4. При необходимости доработать Android-приложение до полноценного продакшен-вида.
5. Уточнить реальные ссылки и изображения для некоторых компонентов в каталоге.

## Чего не делать без явной команды пользователя

- Не публиковать проект.
- Не удалять уже принятые проектные решения.
- Не заменять имя BLE `Crucian`.
- Не возвращать бесконечный BLE после каждого перезапуска.
