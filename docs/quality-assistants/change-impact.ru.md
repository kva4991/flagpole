# Карта влияния изменений

<!-- §impact -->

Команда `npm.cmd run review:impact` анализирует изменённые и новые пути относительно `origin/main`, группирует их по подсистемам и перечисляет обязательные проверки.

Уровни риска:

- `low` — документация;
- `medium` — каталог или quality-инструменты;
- `high` — Android или электрические документы;
- `critical` — механика и прошивка, где ошибка может перейти в физическое изделие.

Неизвестный путь не скрывается и завершает команду ошибкой, пока для него не определена область. Команда ничего не собирает и не меняет на стенде; она только формирует план.
