## Не считать подтверждённым

- любые численные посадки без реальной детали и купона;
- водозащиту как сертифицированный IP-рейтинг;
- электрическую безопасность внешнего аккумулятора 6×18650;
- работу bonding/PIN/PWM только по статическому тесту кода;
- точность климатических датчиков без стенда;
- пригодность тех же STL для ASA без повторных купонов;
- герметичность кабельного ввода и достаточный радиус изгиба без фактического пигтейла и дождевого теста.
