## Не считать подтверждённым

- численные посадки без измерения и купона;
- IP-рейтинг или долговечность на улице;
- безопасную нагрузку и тепловой режим;
- пригодность STL для другого материала без повторной калибровки;
- электрическую безопасность внешнего аккумуляторного блока;
- работу BLE, PWM и датчиков только по статическим тестам.
