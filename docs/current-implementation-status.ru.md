# Текущий статус реализации Crucian v0.6.1

<!-- §status1 -->

Дата среза: 2026-08-01.

| Область | Состояние | Что доказано | Что остаётся |
| --- | --- | --- | --- |
| Механика v0.5 | Сохранена как текущая печатная база | В репозитории есть генераторы, STL, GLB, preview и прежний validation report | Подставить реальные размеры, повторить генерацию и печать купонов |
| Механические требования v0.6.1 | Документированы | Зафиксированы кабельный выход, TPU 85A/95A и сохранение схемы спицы | Геометрия v0.6 под эти решения ещё не создана |
| Электрическая архитектура | Документирована | Внешняя аккумуляторная подсистема 6×18650 подаёт стабилизированные 12 В; внутри Crucian используются DC-DC 5 В, VEML7700 и MOSFET/PWM | Подтвердить входные 12 В и измерить ток нагрузки; BMS/заряд находятся вне проекта Crucian |
| Прошивка v0.5 | Историческая рабочая база | Сохранены исходники и прежний отчёт синтаксической проверки | Не считать её реализацией BLE-функций v0.6 |
| Прошивка Crucian v0.6 | Исправленный прототип исходного кода | Добавлены RTC-блокировка BLE, отсутствие PIN в GATT и fail-safe VEML7700 | PlatformIO build не выполнен; все три изменения требуют стенда |
| Android | Каркас прототипа, build blocked | Присутствуют Compose UI и BLE GATT-клиент; Gradle 8.10.2 воспроизвёл конфигурационную ошибку | Нет Wrapper и Compose Compiler plugin для Kotlin 2.0; после исправления нужны сборка и тест с устройством |
| Каталог компонентов | Воспроизводим | JSON является источником, HTML проходит локальную сверку | Placeholder-изображения и часть ссылок требуют замены после подтверждения деталей |
| Документация | Переведена на контролируемый процесс | Есть быстрый вход, статус, ADR, §-теги, link audit и tests | Обновлять в той же сессии с кодом и измерениями |

## Не заявлять как подтверждённое

- посадки под древко, M125, подшипники и углепластиковую спицу;
- безопасную работу аккумуляторного блока 6×18650;
- корректное BLE-окно после Deep-sleep;
- защищённую смену PIN;
- успешную Android-сборку и сопряжение;
- заявленный IP-рейтинг, уличную долговечность и тепловой режим.

Подробные причины перечислены в [`AUDIT_V061_RU.md`](AUDIT_V061_RU.md).
