# Зафиксированные решения проекта

## 1. Название

По умолчанию проект называется `Crucian`, но название не зашито в нескольких местах. Единственный источник:

```text
project_identity.json
```

Другой владелец может быстро изменить видимое имя программы и BLE-имя через две отдельные переменные.

## 2. Механика

- два подшипника образуют основную опорную базу;
- токосъёмник не является несущей опорой;
- углепластиковая спица Ø5 мм находится между подшипниками;
- спица входит только сбоку и заканчивается до центрального штока;
- кабель к флагу не проходит через спицу и не использует отдельное отверстие над ней;
- герморазъём находится снаружи около флага, а кабель идёт по открытой канавке ниже спицы через наружную низкую точку;
- единственный ввод в электронный бокс уплотняется разрезной TPU95-манжетой `#tpu95-3` / `#tpu95-4`, а рывок принимает внутренний PETG-мостик;
- в v0.6 добавлены параметризованные закладные M4/M3 и купон под реальную гайку;
- AHT20+BMP280 размещается в отдельном нижнем непродуваемом кармане за гидрофобной мембраной;
- окно VEML7700 — отдельная прозрачная вставка с TPU85-прокладкой и PETG-держателем.

## 3. Флаг

- размеры основы: 300 × 250 мм;
- хвост ихтиса слева;
- глаз вырезается насквозь;
- отражайка внутри тела — отдельный кусок;
- отражайка внутри хвоста — отдельный кусок;
- неон Ø16 мм пришивается по стандартному контуру ихтиса;
- четыре петли из той же оранжевой ткани крепят левый край к вертикальному штоку;
- петли не пришиваются к неону или отражайке;
- длина петли окончательно определяется после измерения наружного диаметра штока.

## 4. Материалы

Текущая сборка:

- оранжевый PETG — жёсткие детали;
- TPU 95A — функциональные мягкие элементы;
- TPU 85A — прокладки.

ASA сейчас не покупается и не является обязательным. Если позднее появятся деньги, наружные PETG-детали можно заменить ASA-версиями после повторной калибровки купонов.

Принтер: Bambu Lab X1 Carbon, сопло 0,4 мм.

## 5. Электроника

- внешняя система из 6×18650 подаёт на Crucian стабилизированные 12 В;
- проект не проектирует BMS или зарядное устройство;
- напряжение аккумулятора не измеряется и не показывается;
- ESP32-C3 питается через DC-DC 12→5 В;
- VEML7700 измеряет свет;
- AHT20+BMP280 измеряет температуру, влажность и давление;
- подсветка питается от 12 В и регулируется через MOSFET;
- PWM и MOSFET используются вместе: PWM — управляющий сигнал, MOSFET — силовой ключ;
- допускается прямое подключение PWM к затвору LR7843 после проверки конкретной платы.

## 6. BLE

- BLE-имя берётся из `project_identity.json`;
- после настоящей подачи питания BLE доступен 1 час;
- если никто не прошёл bonding, BLE выключается до следующего power cycle;
- после успешной авторизации BLE остаётся активным до снятия питания или команды `BLE:OFF`;
- Deep-sleep не должен заново открывать BLE-окно;
- PIN изменяемый;
- смена PIN требует старый PIN;
- после смены PIN удаляются старые bond-записи;
- сам PIN не возвращается через GATT.

## 7. Android

Android-клиент использует:

- отдельную BLE state machine;
- последовательную очередь GATT-операций;
- тайм-ауты сканирования, подключения и операций;
- современные write API Android 13+ с fallback для старых версий;
- закрытие `BluetoothGatt` и остановку сканирования;
- обновление состояния интерфейса на main thread;
- локальную калибровку дня и ночи;
- команды AUTO/ON/OFF, яркость, смену PIN и отключение BLE.

## 8. Каталог и 3D

- JSON является источником истины;
- картинки сохраняются отдельными карточками;
- общий вид v0.5, раскладка PETG и разнесённый вид имеют интерактивные варианты;
- у моделей есть полноэкранный режим с кнопкой `×` и Escape;
- у актуальных деталей есть стабильные ID `#petg-*`, `#tpu95-*`, `#tpu85-*`, таблица соответствия и отдельные очереди печати по материалам;
- generated HTML вручную не редактируется.
