# ADR-0029: build123d-mcp как вспомогательный точный CAD-контур

- Статус: Принято
- Дата: 2026-08-02

## Контекст

Текущая параметрическая механика строится SDF-вокселизацией и экспортируется как сетки. Это удобно для сложной формы, но не даёт полноценного B-Rep/STEP-контура для точного измерения признаков и автоматических инженерных чертежей. При этом репозиторий уже содержит достаточные проектные правила, поэтому добавление нескольких универсальных «дисциплин» создало бы дублирующие источники истины.

## Рассмотренные варианты

- сразу заменить всю текущую механику build123d — отклонено как слишком рискованная миграция без физических эталонов;
- подключить несколько перекрывающихся CAD-наборов — отклонено из-за дублирования правил и зависимостей;
- провести ограниченный пилот build123d-mcp на трёх деталях, сохранив текущий генератор каноническим — принято.

## Решение

Подключается только `pzfreo/build123d-mcp` и его процессы `modeling`, `drawing`, `repair`. Инструмент используется для ограниченного пилота `#petg-6`, `#petg-10`, `#petg-5`. Существующий генератор остаётся каноническим до отдельного принятия каждой перенесённой детали. Полный текст внешних навыков не встраивается в `AGENTS.md`; там хранится только ссылка на проектный порядок.

## Последствия

- появляется путь к воспроизводимым STEP и точным сечениям;
- миграция выполняется постепенно без одновременной переделки 23 деталей;
- внешняя MCP-сессия не становится источником истины: результат обязан быть сохранён как Python build123d;
- `text-to-cad`, `draftwright` и Blender-набор не становятся обязательными зависимостями этой версии.

## Проверка

- `tests/cadWorkflowV076.test.mjs` проверяет ограниченный набор процессов и пилотных ID;
- принятая деталь должна воспроизводимо строиться из сохранённого Python-кода;
- STEP/STL сравниваются с текущей геометрией до смены канонического источника.

## Когда пересматривать

- после успешной реализации и проверки пилотов `#petg-6`, `#petg-10`, `#petg-5`;
- при принятии build123d как канонического источника хотя бы одной детали;
- при изменении доступности или интерфейса build123d-mcp.
