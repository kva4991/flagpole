# ADR-0013: единый источник видимого имени проекта и BLE-имени

- Статус: Принято
- Дата: 2026-08-01

## Контекст

Имя проекта используется одновременно в прошивке, BLE-рекламе, Android-приложении и локальном каталоге. Ручная замена строк в нескольких местах легко создаёт несовместимые сборки.

## Рассмотренные варианты

1. Оставить имя жёстко записанным в каждом исходнике.
2. Передавать имя через параметры нескольких независимых сборок.
3. Хранить видимое и BLE-имя в одном JSON и генерировать зависимые файлы.

## Решение

Файл `project_identity.json` является единственным редактируемым источником:

- видимого названия Android-приложения;
- BLE-имени устройства;
- заголовка локального каталога.

Generated-файлы создаёт `scripts/generateProjectIdentity.mjs`.

## Последствия

Другой человек должен иметь возможность заменить `Crucian` на своё имя, не искать строку по прошивке, Android и HTML.

Generated-файлы нельзя редактировать вручную; после изменения JSON обязательны `identity:generate`, генерация каталога и проверки синхронизации.

## Проверка

`npm.cmd run identity:check` сравнивает все generated-файлы с `project_identity.json`; тесты дополнительно проверяют использование констант в прошивке и Android.

## Когда пересматривать

Если появятся дополнительные публичные имена, локализация Unicode для BLE либо иной формат конфигурации сборки.
