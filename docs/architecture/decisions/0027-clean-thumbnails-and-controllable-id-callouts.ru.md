# ADR-0027: чистые миниатюры и управляемые ID-метки

- Статус: Принято
- Дата: 2026-08-02

## Контекст

После введения обязательных ID-выносок каталог показывал подписанные PNG прямо в карточках, а hotspots были видны уже в небольших 3D-просмотрщиках. Это перегружало миниатюры. В полноэкранном просмотре метки нельзя было временно скрыть. Двухмерные рамки располагались по заранее заданным координатам у краёв листа, поэтому линии часто были длиннее необходимого и пересекали другие элементы.

## Рассмотренные варианты

- оставить подписанные миниатюры и добавить только кнопку скрытия — отклонено из-за визуальной перегрузки карточек;
- полностью убрать ID из каталога — отклонено, потому что идентификаторы нужны при сборке и обсуждении деталей;
- хранить чистые миниатюры и показывать управляемые метки только в полном просмотре — принято.

## Решение

1. `catalog/drawings.json` переводится на schemaVersion 4; поле `thumbnail` обязательно для каждой 2D-карточки. Все карточки используют чистую миниатюру без ID.
2. Нажатие на 2D-миниатюру открывает полноразмерную подписанную копию; чистый инженерный источник сохраняется отдельно.
3. Hotspots в карточном 3D-просмотрщике скрыты CSS, но остаются в DOM для копирования в полноэкранный viewer.
4. В полноэкранной панели рядом с крестиком добавляется кнопка с пиктограммой глаза и подписью `ID`. Она переключает видимость всех hotspots и корректно обновляет `aria-pressed`, `title` и `aria-label`.
5. `labelPosition` в JSON становится подсказкой направления. Детерминированный resolver выбирает ближайшую допустимую позицию, не перекрывающую другие рамки, не создающую без необходимости пересечения линий и мягко избегающую контрастных контуров исходной схемы.
6. Генератор сохраняет `mechanical/CALLOUT_LAYOUT_REPORT_V076.json` с длинами линий и фактическими координатами.

## Последствия

- миниатюры лучше показывают сам чертёж или модель;
- ID доступны в полноразмерном режиме и легенде;
- пользователь может очистить 3D-вид одним нажатием, не перезагружая GLB;
- размещение выносок воспроизводимо на Windows/Linux и больше не требует ручного перемещения каждой рамки;
- изменение алгоритма размещения требует регенерации всех `catalog/annotated/*.png` и отчёта.

## Проверка

- `tests/catalogPresentationV076.test.mjs` проверяет чистые миниатюры и доступную кнопку `ID`;
- `render_catalog_part_callouts_v075.py --self-test` проверяет компактность рамок и отсутствие пересечений;
- `npm run catalog:check` подтверждает синхронность JSON, производных PNG и HTML.

## Когда пересматривать

- при смене полноэкранного просмотрщика или формата hotspots;
- если автоматическое размещение снова создаёт пересечения на новых схемах;
- если ID понадобятся непосредственно на печатных раскладках.
