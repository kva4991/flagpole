## Название устройства

BLE имя:

```
Crucian
```

Не менять.

---

# Питание

Источник:

- 6 аккумуляторов 18650;
- далее стабилизация;
- на флагшток подаётся 12 В.

Не считать устройство питающимся от сети.

---

# BLE

Логика:

После подачи питания:

```
12 В
 ↓
ESP32-C3 запускается
 ↓
BLE advertising включён
 ↓
1 час ожидания подключения
```

Если никто не подключился:

```
BLE выключается
```

Повторное включение:

только после следующего полного отключения и включения питания.

---

## Если пользователь подключился

После успешного bonding:

```
BLE остаётся включённым
```

До:

- отключения питания;
- команды BLE:OFF из приложения.

НЕ сохранять флаг "BLE всегда включён" между перезапусками.

Это было специально принято пользователем.

---

# PIN BLE

Требования:

- PIN изменяемый;
- смена только после ввода старого PIN;
- новый PIN должен инвалидировать старые авторизации.

После смены PIN:

- удалить BLE bond записи;
- разорвать старую сессию;
- потребовать новое сопряжение.

Заводской код первого подключения `123456` публичен по конструкции и должен быть
сменён до постоянной установки. Действующий PIN не должен возвращаться через GATT.

# Android приложение

Название:

```
Crucian
```

Иконка:

- чёрный флагшток;
- схематичный оранжевый флаг.

Функции:

- поиск Crucian;
- подключение;
- статус;
- яркость;
- режим AUTO/ON/OFF;
- калибровка VEML7700;
- смена PIN;
- выключение BLE.

---

# Калибровка VEML7700

Это важная функция.

Причина:

невозможно заранее правильно рассчитать освещённость внутри светового тоннеля.

Приложение должно позволять:

- установить текущий уровень как день;
- установить текущий уровень как ночь.

---

# Подсветка

Используется:

- XUNATA Round Neon Light 12V 16 мм.

Глаз рыбы:

- не подсвечивается;
- вырезается насквозь.

---

# PWM и MOSFET

Не выбирать между ними.

Правильно:

```
ESP32-C3 PWM
        |
        |
        Gate MOSFET
        |
        |
12V Neon
```

PWM — метод управления.

MOSFET — силовой ключ.

---

# PC817 + LR7843

Модуль можно использовать.

Допускается:

- подпаяться непосредственно к затвору MOSFET;
- обойти PC817.

Проверить на прототипе.

---

# Внешний PWM контроллер

Не использовать.

Причины:

- один канал;
- ESP32-C3 имеет аппаратный PWM;
- дополнительная плата увеличивает количество отказов.

---

# Материалы печати

Принтер:

```
Bambu Lab X1 Carbon
сопло 0.4 мм
```

Основной пластик:

```
PETG оранжевый
```

Мягкие материалы:

## TPU 95A

Использовать:

- демпферы;
- фиксаторы;
- кабельные разгрузки;
- силовые мягкие элементы.

## TPU 85A

Использовать:

- прокладки;
- уплотнения;
- элементы, где нужна большая деформация.

---

# Механика

Спица:

```
углепластик Ø5 мм
```

Расположение:

- между верхним и нижним подшипниками;
- входит сбоку;
- не доходит до центральной оси.

---

# Кабель к рыбе

Важно:

- не через спицу;
- через отдельное отверстие корпуса;
- отверстие максимально близко к флагу;
- но с усилением стенки.

Обязательно:

- TPU разгрузка кабеля;
- механическое удержание;
- отсутствие нагрузки на пайку.
