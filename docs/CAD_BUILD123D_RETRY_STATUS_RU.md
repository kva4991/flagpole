# Статус повторной попытки полной CAD-линии build123d

Дата среза: 2026-08-04.

## Цель проверки

Исходное задание требует сохранить каноническую SDF/trimesh-линию и параллельно построить экспериментальную линию для всех 23 печатных деталей по цепочке:

```text
Python/build123d → STEP/B-Rep → STL/GLB → чертежи и сравнение → третья вкладка каталога
```

До решения владельца эксперимент не заменяет старые файлы, не используется для изготовления и не объединяется с основной веткой.

## Что подтверждено повторно

1. Исходный снимок рабочего дерева проверен по 411 внутренним SHA-256 без расхождений.
2. Канонический `mechanical/generate_models_v06.py` выполнен в отдельной полной копии дерева с кодом 0.
3. Сравнены 40 STL, 7 GLB и 2 JSON-отчёта: **49/49 эквивалентны**. Полный протокол находится в:
   - `docs/LEGACY_CAD_REGENERATION_AUDIT_RU.md`;
   - `mechanical/LEGACY_REGENERATION_AUDIT_V076.json`.
4. Основное рабочее дерево при повторной генерации не перезаписывалось.
5. Commit, push, merge и PR не выполнялись.

## Что было проверено в исходной изолированной среде

Фактическая среда:

- Python 3.13.5;
- модуль `build123d` отсутствует;
- модуль `OCP` отсутствует;
- FreeCAD и OpenSCAD отсутствуют;
- настроенный в среде индекс `pip` не содержит `build123d`, `cadquery-ocp-novtk` или `cadquery-ocp`;
- прямое получение бинарного колеса OpenCascade из внешнего хранилища в этой среде завершилось ошибкой загрузки/разрешения имени.

Эти сведения описывают прежнюю Linux-среду подготовки архива и больше не
являются текущим состоянием Windows-компьютера владельца.

## Что установлено на Windows 2026-08-04

- FreeCAD 1.1.3 через `winget install --id FreeCAD.FreeCAD --exact` в стандартную пользовательскую папку Windows;
- OpenSCAD 2021.01 через `winget install --id OpenSCAD.OpenSCAD --exact` в стандартную папку Windows;
- отдельная Python 3.12-среда `%USERPROFILE%\Documents\pesochnica\flagpole\.venv-build123d`;
- build123d 0.11.1;
- `cadquery-ocp-novtk` 7.9.3.1.1, предоставляющий импорт `OCP`.

Импорты `build123d` и `OCP` успешно проверены. Воспроизводимый установщик —
`tools/windows/setup-cad.ps1`; общий `tools/windows/setup.ps1 -Install` также
вызывает его.

## Граница результата

Построен первый честно ограниченный пилот:

- #petg-5, #petg-6 и #petg-10 имеют native build123d/OCP STEP и STL;
- гибридный GLB #211 содержит эти три B-Rep-пилота и двадцать канонических сеток;
- отдельная вкладка «Новый CAD» изолирует эксперимент от текущей #204;
- JSON-отчёт фиксирует 23 узла, три native-узла и двадцать legacy-узлов.

По-прежнему **не создавались и не выдаются за готовые** полные 23 STEP/B-Rep,
полные экспериментальные производственные STL, численное сравнение всех тел и
утверждение полной миграции.

Создание фиктивных STEP, переименование STL старой линии или выдача упрощённых схем за B-Rep запрещены. Это сохранило честную границу доказательства, но означает, что исходный критерий полной параллельной CAD-линии пока не выполнен.

## Как повторить установку

Минимальный порядок:

```powershell
powershell -ExecutionPolicy Bypass -File tools\windows\setup-cad.ps1 -Install
```

Продолжать нужно строго по `mechanical/docs/BUILD123D_MCP_WORKFLOW_RU.md`: сначала сравнить три пилота, затем после решения владельца переносить остальные двадцать деталей. Старый CAD остаётся каноническим до отдельного выбора владельца.
