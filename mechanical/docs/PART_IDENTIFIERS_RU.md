# Идентификаторы печатных деталей v0.6

Для всех актуальных механических чертежей введены стабильные идентификаторы вида `#petg-1`, `#tpu95-3`, `#tpu85-2`.

Правило простое:

- одинаковая деталь имеет один и тот же ID во всех v0.6-чертежах;
- ID привязан к типу детали, а не к конкретной картинке;
- исторические картинки v0.5 не переименовываются задним числом.

## PETG

- `#petg-1` — ротор, половина A
- `#petg-2` — ротор, половина B
- `#petg-3` — неподвижный воротник, половина A
- `#petg-4` — неподвижный воротник, половина B
- `#petg-5` — сервисная крышка
- `#petg-6` — световой тоннель VEML7700
- `#petg-7` — прижим прозрачного окна
- `#petg-8` — съёмный карман AHT20+BMP280

## TPU 95A

- `#tpu95-1` — втулка спицы, половина A
- `#tpu95-2` — втулка спицы, половина B
- `#tpu95-3` — ввод кабеля питания флага в электронный бокс, половина A
- `#tpu95-4` — ввод кабеля питания флага в электронный бокс, половина B
- `#tpu95-5` — разгрузка жгута M125, половина A
- `#tpu95-6` — разгрузка жгута M125, половина B
- `#tpu95-7` — втулка под M125 / шток
- `#tpu95-8` — вкладыш воротника по штоку, половина A
- `#tpu95-9` — вкладыш воротника по штоку, половина B

## TPU 85A

- `#tpu85-1` — прокладка крышки
- `#tpu85-2` — прокладка окна VEML7700
- `#tpu85-3` — прокладка кармана AHT20+BMP280
- `#tpu85-4` — прокладка PTFE/ePTFE-мембраны

## Где эти ID нанесены

ID нанесены на:

- разнесённый вид v0.6;
- раскладку PETG v0.6;
- раскладку TPU 95A v0.6;
- раскладку TPU 85A v0.6.

Это сделано для того, чтобы человек без истории чата мог быстро сверить:

1. что печатать;
2. чем печатать;
3. где именно эта деталь показана на картинке;
4. какой STL-файл ей соответствует.
