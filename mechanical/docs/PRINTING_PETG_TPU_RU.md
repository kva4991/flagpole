# Печать v0.7 на Bambu Lab X1 Carbon, сопло 0,4 мм

## 1. Материалы этой версии

```text
жёсткие детали сейчас:  оранжевый PETG
функциональные мягкие:  TPU 95A
статические прокладки:  TPU 85A
будущая замена PETG:    ASA, только после повторных купонов
```

Не переносить температуры и посадочные компенсации PETG на ASA.

## 2. Обязательный порядок

Перед первой локальной генерацией установить изолированные зависимости механики:

```powershell
python -m pip install -r mechanical\requirements.txt
```

`resvg-py` используется для PNG-схем без системной библиотеки Cairo, поэтому отдельная установка GTK/Cairo на Windows не требуется.

1. Высушить катушку.
2. Создать отдельный профиль каждой катушки в Bambu Studio.
3. Откалибровать flow ratio и pressure advance.
4. Напечатать купоны.
5. Измерить их после полного остывания.
6. Подставить выбранные значения в `generate_models_v06.py`.
7. Перегенерировать STL.
8. Только затем печатать корпус.

## 3. Оранжевый PETG

Стартовый профиль, который затем уточняется под производителя:

```text
сопло:                   240–245 °C
стол:                    75–85 °C
слой:                    0,20 мм
первый слой:             0,22–0,24 мм
внешняя линия:           0,42–0,45 мм
внутренняя линия:        0,45–0,48 мм
```

### Прочность корпуса

```text
стенки:                  7
верх/низ:                6 слоёв
заполнение:              40% Gyroid
внешняя стенка:          35–45 мм/с
внутренняя стенка:       55–70 мм/с
первый слой:             18–25 мм/с
```

Не использовать предельную скорость X1 Carbon для несущих деталей. Межслойное сплавление важнее времени печати.

### Обдув

```text
первые 3 слоя:           0%
обычная печать:          20–30%
короткие мосты:          до 45–55%
Aux Fan:                 выключен или минимум
```

### Прилипание

- половины корпуса: brim 8–12 мм;
- крышка: 4–6 мм;
- воротник: 3–5 мм;
- световой тоннель: 3–4 мм.

На гладкой пластине использовать разделительный слой, если PETG слишком сильно сцепляется с поверхностью.

### Ориентация

- половины корпуса — плоскостью разъёма на стол;
- половины воротника — плоскостью разъёма вниз;
- крышка — внешней верхней поверхностью вниз;
- световой тоннель — вертикально;
- карман AHT20+BMP280 — открытой стороной вверх;
- кольцо окна — плоско.

Поддержки внутри посадок, карманов гаек и каналов запрещены.

## 4. TPU 95A

Используется для деталей, которые должны держать форму под прижимом.

```text
сопло:                   220–230 °C, начать 225 °C
стол:                    40–50 °C, начать 45 °C
слой:                    0,20 мм
скорость стенок:         18–25 мм/с
малые элементы:          15–20 мм/с
стенки:                  4
заполнение:              100%
обдув после 2-го слоя:   30–50%
ретракт:                 минимальный
```

TPU печатать с внешней катушки, без попытки проталкивать мягкий материал через стандартный AMS-тракт.

Ориентация:

- разрезные половины — плоскостью разъёма вниз;
- втулка M125 — вертикально;
- поддержки выключены.

## 5. TPU 85A

TPU 85A мягче и сильнее реагирует на подачу и ретракт. Начальный профиль:

```text
сопло:                   220–230 °C
стол:                    35–45 °C
слой:                    0,20 мм
скорость:                12–20 мм/с
стенки:                  4
заполнение:              100%
ретракт:                 минимально возможный
ускорение:               ниже, чем для TPU95
```

Печатать по одной или небольшой группой:

- прокладка крышки;
- прокладка окна;
- прокладка кармана;
- прокладка мембраны.

После печати дать детали полежать без нагрузки и проверить восстановление после 24 часов пробного сжатия.

## 6. Купоны

Сначала печатать:

1. подшипники 32,20 / 32,35 / 32,50 мм;
2. M125 15,60 / 15,80 / 16,00 мм;
3. закладную M4;
4. утончения 0,6 / 0,8 / 1,0 мм;
5. PETG-паз + TPU85-прокладку крышки;
6. пробные прокладки окна и климатического кармана.

## 7. Закладные гайки

Карманы нельзя исправлять глобальным масштабированием модели. Изменять только параметры:

```text
m4_nut_pocket_across_flats
m4_nut_snap_entry_across_flats
m3_nut_pocket_across_flats
m3_nut_snap_entry_across_flats
```

## 8. Переход на ASA позднее

Когда будет куплена ASA:

1. использовать закрытый корпус X1 Carbon и безопасную вентиляцию помещения;
2. создать отдельный профиль;
3. повторить все PETG-купоны;
4. проверить коробление длинных половин;
5. не считать прежний PETG fit подтверждением ASA fit.

## 9. После печати

- не запрессовывать подшипники ударами;
- убрать только заусенцы;
- проверить гайки до окончательной сборки;
- собрать половины с шайбами и умеренным моментом;
- проверить вращение после каждого шага затяжки;
- выполнить дождевой тест без питания.

## 10. Раздельные очереди печати

Для текущего проекта за один запуск печатается только **один основной пластик**.

Правило:

- очередь 1 — PETG;
- очередь 2 — TPU 95A;
- очередь 3 — TPU 85A.

Не смешивать PETG, TPU 95A и TPU 85A в одной печати только ради экономии времени: на Bambu Lab X1 Carbon это приводит к лишним сливам материала и усложняет контроль качества.

Допустимое исключение:

- сервисные подложки или вспомогательные элементы для резиновых деталей, если они реально нужны именно в этой очереди.

## 11. Цвет отображения белых деталей на рендерах

Белые или очень светлые детали на новых рендерах умышленно показаны **сероватыми**. Это сделано только для читаемости изображений: на светлом фоне чисто белые TPU-детали и прокладки почти пропадают.

На реальные материалы это правило не накладывает ограничений: серый цвет в рендерах не означает, что деталь должна быть напечатана серым пластиком.
