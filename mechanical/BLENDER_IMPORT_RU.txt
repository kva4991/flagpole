BLENDER — АКТУАЛЬНАЯ СБОРКА v0.7.3

Вариант 1:
Файл -> Импортировать -> glTF 2.0 -> flagpole_finial_v0_6_assembly.glb

Имя файла v0_6 сохранено ради совместимости ссылок, но его содержимое соответствует v0.7.3.

Вариант 2:
1. Открыть рабочее пространство Scripting.
2. Открыть create_blend_file.py.
3. Нажать Run Script.
4. Рядом будет создан flagpole_finial_v0_7_3.blend.

GLB хранит координаты в метрах по стандарту glTF, но физические размеры деталей соответствуют миллиметровым STL.
